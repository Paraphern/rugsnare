## 1. Паспорт продукта сейчас

**Caveman** (github.com/JuliusBrussee/caveman, caveman.so) — OSS-стек экономии токенов для AI-кодинг-агентов: скилл «говори кратко» (Says less, −65% output-токенов чата) + прокси сжатия входа (Reads less, −33.2% input, самоотчёт) + роутинг моделей/effort (Auto, «54% дешевле Opus», самоотчёт) + Blocks (переиспользуемые агентные скрипты, pre-release) + Browse (сжатие веб-страниц). Весь репо Apache-2.0 (с v3.0.0), имя и rock-logo — заявленные товарные знаки Julius Brussee (Nice 9/42, регистрация pending, в USPTO/EUIPO не найдена). Компания: **YC F26** (анонс 13.10.2026). Монетизация: Caveman Cloud — Free / **Team $300/мес** (без сидов, usage-based, 0% markup на токены) / Enterprise (VPC, Helm). Состояние: живой, 114,097 звёзд (21.10.2026, [факт GitHub API]), 6,573 форка, 1,822 коммита, 90 контрибьюторов, npm @caveman-ai/cli 76,780 загрузок/мес [факт], 4.3M установок скиллов [факт skills.sh]. **Выручка не раскрыта** — платный продукт существует с 13.10.2026.

## 6. Критика и кризисы (не умер ни разу)

1. **«Бенчмарк-гейт» (4–8.04)**: «нет пруфов» на HN (интервенция модератора dang), issue #18 → признание Brussee на HN: «my ~75% is from preliminary testing, that should be phrased more carefully» → v1.1.0 «Real Benchmarks».
2. **«Токены = единицы мышления» (05.04, HN)**: форсированная краткость «делает модель тупее» → ответ: JetBrains p=0.82 в README.
3. **«be brief» делает то же (29.04)**: maxtaylor — те же токены/качество двумя словами → ответ: смещение ценности в persistence/структуру/прокси.
4. **Adobe наполовину убил фичу (23.06)**: input-компрессия «strict lose-lose» (до 2.7× дороже) → пивот: «caveman never touches your prompt» — Read less перестал трогать промпт.
5. **JetBrains 8.5% (06.07)**: публичное «called bullshit» → ассимиляция: критик процитирован в README, клеймы разделены по нагрузкам (v1.10.0).
6. **Волна самокритики (август)**: field reports «снятие токенов подняло счёт», «бенчмарк выдал 26.5% — мы отказались публиковать», jayn.app (21.08): в реальных сессиях +0.01%, комплаенс затухает к 80-му ходу; заморозка сателлит-репо, консолидация.
7. Баги-рекорды: #303 «drifts back to prose», #550 (задача 4M токенов vs 1M без caveman), волна сломанных инсталлов OpenCode (#366 12👍, #426 18👍) — все закрыты.

## 7. Противоречия (честно)

- **75% → 65% → 8.5%**: исходный мем-клейм → собственный бенчмарк → независимый A/B; консенсус комьюнити: скилл режет только output, реальные 10–15% на агентных сессиях, 65% — только чистый чат.
- 33.2% input и 54% Auto — самоотчёты с открытыми методиками и секцией ограничений (HONEST-NUMBERS признаёт: скилл даёт 0% input; vs контроль «Answer concisely» — лишь 3%); независимой проверки этих цифр нет; Adobe подтверждает только «стиль укорачивает output в 1.4–2.4×».
- **Авторство мема**: Brussee — не автор вирусного поста (u/ffatty) и не автор твита (Om Patel); его вклад — упаковка волны в канонический репо за 6 часов. Совпадение тайминга намекает, но не доказывает связь с u/ffatty.
- ThePrimeagen-видео (~649K) — по вторичным источникам; прямой клип не верифицирован.
- LinkedIn указывает «United States», голландские СМИ и Лейден — Нидерланды.

## 8. Уроки (строго из собранного)

1. **Волна существовала до продукта**: репо создан через 16 часов после чужого вирусного поста — скорость упаковки мема в one-command-инструмент решила, чьим именем назовут феномен.
2. **Юмор как дистрибуция**: тэглайн-мем сделал starring развлечением (CSDN: «звёзды из любопытства»), а чужой контент — бесплатным промо (СМИ писали посты на языке бренда).
3. **Капитуляция честностью как стратегия**: каждый разгром (maxtaylor, Adobe, JetBrains, jayn) конвертировался в цитату в README или field report — «честные цифры» стали ровом, который клоны скопировать не могут.
4. **Разделение клеймов спасло доверие**: «65% чат vs 8.5% агентный код» вместо защиты единой цифры.
5. **Лестница перезапусков**: один репо, серия «новых» событий с интервалом в месяцы (Reddit→HN→PH→404media→JetBrains→Primeagen→YC) — три звездных спайка вместо одного.
6. **Продуктовая лестница из ничего**: скилл (апрель) → движок сжатия (август) → Apache-2.0+телеметрия (сентябрь) → роутинг/Cloud/$300 (октябрь): каждая ступень создавала следующую и легитимность для неё.
7. **Скриншоты «было→стало»** («22,810→348», «счёт за ИИ ниже счёта за еду») конвертировали проценты в проверяемые артефакты лучше любых графиков.
