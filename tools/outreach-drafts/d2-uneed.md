## Заполнение

- Name: RugSnare
- Tagline (10-80 символов): `Pin MCP tool contracts. Fail CI on silent drift.` (49 символов)
- URL: https://rugsnare.com (лендинг есть; требование Uneed - чёткий лендинг с тэглайном)
- Description:

```
AI agents trust the tools they are given. RugSnare makes that trust
verifiable: when you approve an MCP server, every tool contract (name,
description, schemas, annotations) is pinned with SHA-256. If the server
silently changes anything later - a rewritten description with hidden
instructions, a mutated schema, a new tool that should not be there - your
CI fails with a precise diff.

Why it matters: our October 2026 audit of the most-installed MCP servers on
npm found 218 silent contract changes, including @azure-devops/mcp removing
75 tools inside minor releases.

Zero dependencies. 394 tests. Apache-2.0. Releases pinned on-chain.
```
