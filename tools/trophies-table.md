Проверены все: `последний релиз > 2026-06 ИЛИ >50 dl/wk`. **PASS у всех 18 оставшихся** (граничные: sondv5 — 32 dl/wk, но релиз 2026-09-25; aether — 4 dl/wk, но релиз 2026-09-08). **Исключён `binance-mcp-tools`:** последний релиз 2026-03-08 (до июня) при 22 dl/wk — не проходит ни одно из двух условий инструкции.

**Ключевой вывод:** даже там, где издатель честен в документации (4 из 18), пользователь всё равно получает изменение контракта без переодобрения — что и есть продуктовая ниша RugSnare. Самый показательный раскол — jadchene: README и контракт говорят о подтверждениях противоположное.
