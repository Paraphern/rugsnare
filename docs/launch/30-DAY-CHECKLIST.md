# 30-day post-launch checklist

Framework from PR #21 (ChatGPT-агент, 2026-11-06), адаптирован под rugsnare@1.6.0.
Day 1 начинается только после слова юзера на лонч. Все цели — предложения, не обязательства.

| Окно | Работа / гейт | Измеримая цель | На старте |
|---|---|---|---|
| День 0 | Юзер даёт слово на лонч; фиксируем snapshot (stars, downloads, npm weekly) | Snapshot записан | Не начат |
| Дни 1–7 | HN-пост (Show HN) + X-тред + r/MCP data-пост; локальный демо | ≥5 технических фидбек-комментариев | Не начат |
| Дни 8–14 | Разбор фидбека; подготовка fixture-only CI-интеграций (по согласию) | 2 воспроизводимых внешних CI-примера | 0 |
| Дни 15–21 | Разбор FP и репортов; опциональные opt-in установки | 5 opt-in репортов (версия, OS, результат) | 0 |
| Дни 22–30 | Ретроспектива (только если оправдана данными) | Принятые коррекции + CI-примеры + limits | Не начат |

## Правила

- **Opt-in only**: для репортов просим только версию, OS/Node, воспроизводимую команду/результат и опциональный публичный CI URL. Не просим токены, production-промпты, приватные схемы или личные данные.
- **Stars ≠ installations ≠ users**: npm download totals — это события загрузки, не уникальные активные юзеры.
- **Stop/hold критерии**: mismatch версий; отсутствие artifact verification; сломанный install/demo; необъяснимый CI fail; сайт недоступен; правила канала запрещают пост.
- **Не воскрешать** стёртые аутричи и не репостить для компенсации недостающих результатов.

## Денominator дисциплина

В каждой ретроспективе: разделяй цели, наблюдаемые числа, даты и знаменатели. "30 звёзд" без стартового snapshot — не измерение.
